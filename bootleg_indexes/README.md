# bootleg-indexes

Custom index construction from multiple time series.

**Status: placeholder — not yet implemented.**

This module will provide tools for constructing composite indexes from multiple `bootleg-datafeed` series (e.g., custom weighted aggregates, diffusion indexes, normalization and rebasing).

## Installation

```bash
pip install bootleg-indexes
```

### Dependencies

- `bootleg-datafeed >= 0.1`
- `pandas >= 2.0`
- `numpy >= 1.0`
